# Annex A — ISO 27001 Control Assessment Summary  
### Veridian Resources (Fictional Case Study for Learning & Portfolio Demonstration Purposes Only)

This annex provides a structured assessment of 38 ISO/IEC 27001:2022 Annex A controls across 14 domains.  
The evaluation reflects expert-level analysis of control maturity, risk exposure, and organisational impact.

---

## 📘 Assessment Method

Each control was assessed using the following criteria:

- **Implementation Status** — Implemented, Partially Implemented, Not Implemented  
- **Risk Rating** — Low, Medium, High  
- **Expert Commentary** — Observations on gaps, weaknesses, and implications  

This assessment forms the foundation for the risk‑based certification roadmap.
